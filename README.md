# Chess‑Sharp

## 📄 Описание
Консольная шахматная игра на C#. На ветке `develop` реализован базовый движок: правила ходов, проверка шаха/мата, вывод доски в консоль. В будущем: бот, веб‑версия, сохранение партий и мультиплеер.

## 🎮 Демонстрация
![img](images/chessConsolePlay.gif)  
<sub>Рабочий прототип в консоли: доска отрисовывается, фигуры перемещаются, проверяются шах и мат.</sub>

---

## 📁 Структура проекта
- **Board/** – логика шахматной доски и её состояния.  
- **Pieces/** – классы фигур (Pawn, Rook, Knight, Bishop, Queen, King) с методами расчета допустимых ходов.  
- **Logic/** – правила игры, проверка шаха/мата, генерация ходов.  
- **UI/Console/** – отображение доски, ввод ходов пользователем, взаимодействие с игроком.  
- **Player/** – классы игроков (Human, в будущем – AI, NetworkPlayer).  
- **Program.cs** – точка входа в приложение, запуск цикла игры.

---

## ✅ Что уже реализовано
- Консольная доска с отображением фигур
- Базовая проверка правил ходов (включая шах и мат)
- Выбор и совершение ходов через консоль
